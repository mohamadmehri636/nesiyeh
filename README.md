# نسیه | Nesiyeh

سامانه مدیریت حساب‌های دفتری کسب‌وکارها؛ با معماری چندمستاجری (Multi-Tenant)، دفتر مالی تغییرناپذیر (Immutable Ledger) و رابط فارسی.

## وضعیت

این مخزن از Foundation آغاز می‌شود. در این مرحله قراردادهای معماری، مستندات، تنظیمات پایه و اسکریپت‌های راه‌اندازی ثبت می‌شوند؛ هنوز ماژول مالی یا API عملیاتی پیاده‌سازی نشده است.

## پشته مصوب

- Backend: Laravel 13 / PHP 8.5
- Database: PostgreSQL 16
- Web: Blade + Tailwind CSS + Alpine.js
- Android: Kotlin + Jetpack Compose
- API: REST /api/v1
- Authentication: OTP با provider مستقل؛ Sanctum برای نشست و توکن API
- Architecture: Modular Monolith

## ساختار مخزن

- `backend/`: پروژه Laravel (در گام بعد با Composer ایجاد و commit می‌شود)
- `android/`: اپلیکیشن Android (در مرحله مستقل Android Studio ایجاد می‌شود)
- `docs/`: تصمیمات معماری و قواعد کسب‌وکار
- `scripts/`: اسکریپت‌های راه‌اندازی امن و قابل تکرار

## شروع کار

پیش‌نیازها و روش راه‌اندازی در `docs/DEVELOPMENT.md` آمده است. فایل‌های واقعی محیط مانند `.env`، کلیدها، رمزها و توکن‌ها نباید وارد Git شوند.

## اصول غیرقابل مذاکره

1. هر درخواست فقط در محدوده Business مجاز اجرا شود؛ کنترل Tenant در سمت سرور الزامی است.
2. مانده حساب از جمع تراکنش‌های دفتر محاسبه می‌شود، نه از یک مقدار قابل ویرایش مستقل.
3. تراکنش مالی حذف یا ویرایش مستقیم نمی‌شود؛ اصلاح از طریق عملیات جبرانی ثبت خواهد شد.
4. مبلغ به صورت عدد صحیح ریال (BIGINT) ذخیره می‌شود؛ استفاده از float ممنوع است.
5. زمان در پایگاه داده UTC و در رابط کاربری محلی/شمسی نمایش داده می‌شود.
6. تغییرات هر مرحله پس از Build و Test و تأیید، در Git checkpoint ثبت می‌شوند.

## مجوز

پیش از تعیین مجوز انتشار، استفاده یا توزیع، وضعیت مالکیت و مجوز پروژه مشخص خواهد شد.
