# Android

کلاینت Android در مرحله مستقل با Android Studio ایجاد خواهد شد.

پشته مصوب:
- Kotlin + Jetpack Compose
- Clean Architecture + MVVM
- Retrofit برای REST API
- Room برای cache محلی
- Hilt برای Dependency Injection
- Coroutines و Flow

این کلاینت فقط از API نسخه‌دار استفاده می‌کند؛ اتصال مستقیم به PostgreSQL ممنوع است. فعلاً پروژه Gradle ناقص یا فایل‌های ساختگی در این مسیر قرار داده نشده‌اند.
